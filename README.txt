Burning Empires Elephants - Standalone Installer v5

WHAT THIS INSTALLER DOES
- Creates a separate module named "Burning Empires - Elephants Standalone".
- Copies the installed BurningEmpires_Elephants module into the standalone folder.
- Installs the exact standalone runtime DLL verified from the user's successful in-game test.
- Applies the Aserai market XML settings to the standalone copy only.
- Leaves the original BurningEmpires_Elephants module unchanged.
- Creates a backup before replacing an existing standalone installation.

MARKET SETTINGS
- Elephant: 75,000 denars
- Basic elephant harnesses: 5,000 denars each
- Bronze armor: 15,000 denars
- Iron armor: 25,000 denars
- Royal armor: 40,000 denars
The elephant and elephant armor/harness items are marked as Aserai merchandise.
Availability and stock frequency should be tested in-game; these settings do not guarantee a specific rarity.

INSTALLATION
1. Install Burning Empires Elephants first.
2. Extract the entire installer ZIP to a normal folder.
3. Run Install-ElephantsStandalone.bat.
4. If asked, provide the Bannerlord game folder containing the Modules folder.
5. Launch Bannerlord and enable "Burning Empires - Elephants Standalone".
6. Test the standalone module before disabling/removing the original module.

NOTES
- Keep the original module installed until the standalone copy has been tested.
- The installer does not modify the original module.
- If replacing an existing standalone copy, it asks first and makes a timestamped backup.
